# Contributing

Thank you for your interest in contributing to this project! 🎉

All contributions, bug reports, bug fixes, documentation improvements,
enhancements, and ideas are welcome.

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue and include:
- A clear and descriptive title
- Steps to reproduce the problem
- Expected behavior vs. actual behavior
- Screenshots or error messages, if applicable
- Your environment details (OS, browser, version, etc.)

### Suggesting Enhancements

Enhancement suggestions are tracked as GitHub issues. When creating one,
please include:
- A clear and descriptive title
- A detailed description of the proposed enhancement
- Why this enhancement would be useful
- Any examples or references, if relevant

### Submitting Bug Fixes and Enhancements

1. Fork the repository.
2. Create a new branch for your change:
   ```
   git checkout -b feature/your-feature-name
   ```
3. Make your changes, following the existing code style where possible.
4. Test your changes to make sure everything works as expected.
5. Commit your changes with a clear, descriptive commit message.
6. Push your branch to your fork:
   ```
   git push origin feature/your-feature-name
   ```
7. Open a Pull Request against the main repository, describing what you
   changed and why.

### Documentation Improvements

Typos, clarifications, and better examples in documentation are always
appreciated. Feel free to open a pull request directly for small fixes,
or open an issue first for larger changes.

### Ideas

Have an idea but aren't sure how to implement it? Open an issue to start
a discussion — we're happy to talk it through.

## Code of Conduct

By participating in this project, you agree to abide by the project's
[Code of Conduct](CODE_OF_CONDUCT.md).

## Questions?

If you have any questions, feel free to open an issue and we'll do our
best to help.

Thank you for helping improve this project! 🙌
